# Support

iSystem OS is a community-supported public beta. No uptime, response-time, maintenance, migration, or compatibility guarantee is included.

## Where to ask

- Use [GitHub Discussions](https://github.com/AfifiNL/isystem-os/discussions) for setup help, design questions, and ideas.
- Use [GitHub Issues](https://github.com/AfifiNL/isystem-os/issues) for reproducible defects in the public repository.
- Use a [private Security Advisory](https://github.com/AfifiNL/isystem-os/security/advisories/new) for vulnerabilities.

Before asking, remove secrets and personal data, search existing threads, and include the public commit, deployment model, runtime version, relevant sanitized logs, and reproduction steps.

## Scope

Community maintainers may help with the public source and documentation. They cannot diagnose private forks, access deployments, recover data, configure third-party accounts, or provide legal, tax, security, or compliance advice.

Commercial support, managed hosting, and service-level agreements are not announced by this repository. Do not infer availability from the iSystem marks or brand site.
