# Roadmap

This roadmap communicates direction, not a promise of dates or delivery. Items move only when implementation and verification evidence exist.

## Now: trustworthy public beta maintenance

- Keep the v0.1.0 source snapshot reproducible and its release evidence current.
- Turn candidate product areas into Verified beta journeys one at a time, starting with the website-to-enquiry path.
- Rehearse backup restore, provider failure, and operator rollback against synthetic environments for every deployment profile.
- Keep dependency, secret, license, asset, and runtime-image scans green.

## Next: reusable service operations

- Stabilize configuration for branding, locales, modules, and workspace defaults.
- Strengthen the enquiry-to-booking-to-delivery workflow.
- Improve portal, agreement, invoice, and delivery-evidence interoperability.
- Add safe synthetic demo-data tooling after schema validation.
- Expand operator diagnostics, backup guidance, and upgrade checks.

## Later: broader self-hosting and ecosystem

- Validate a fully self-hosted Supabase deployment.
- Define stable extension points and provider adapters.
- Publish compatibility and deprecation policies before a stable release.
- Establish documented release cadence and long-term support criteria.

Feature requests are welcome, but security, tenant isolation, data durability, maintainability, and honest documentation take priority over feature count.
